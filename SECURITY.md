# Security policy

If you find a vulnerability in carlos.nz, please report it privately through
https://carlos.nz/contact/?topic=privacy rather than opening a public issue.
Include steps to reproduce. I'll acknowledge within 5 working days.

Please don't access other people's data, degrade the site, or run automated scanners
against it. Good-faith research within these limits is welcome.

Security design: see `docs/SECURITY-AND-PRIVACY.md`.
